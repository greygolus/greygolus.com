## 🌌 Overview
Welcome to the digital residence of my portfolio. This site is a high-performance, visually immersive experience built to showcase the intersection of **Optical Engineering** and **Computational Design**. 

From levitating nanoparticles to paraxial ray tracing, every project here is an exploration of light, physics, and code.

## 🛠️ Tech Stack
This portfolio isn't just a static page; it's an interactive simulation:
- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **3D Engine**: [Three.js](https://threejs.org/) via [@react-three/fiber](https://github.com/pmndrs/react-three-fiber)
- **Animations**: [GSAP (GreenSock)](https://greensock.com/) & [Framer Motion](https://www.framer.com/motion/)
- **Styling**: Vanilla CSS & Tailwind CSS for precision layouts
- **Experience**: [Lenis](https://github.com/darkroomengineering/lenis) for buttery-smooth kinetic scrolling

## 🧪 Featured Work
### 🔬 Quantum Optomechanics
Research on levitated nanoparticles cooled toward their motional ground state within high vacuum environments.
- **Tools**: MATLAB, Quantum Physics, Laser Diagnostics

### 🎯 Interferometry
Deep analysis of interference patterns to measure laboratory laser wavelengths with precision.
- **Tools**: MATLAB, Physics Modeling, Web Simulation

### 💡 Stage Lighting
Theatrical lighting design focusing on color theory and atmospheric manipulation.
- **Tools**: Vectorworks, ETC EOS, Color Theory

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/greygolus/greygolus.com.git

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
